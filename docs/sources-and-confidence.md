# Sources and Confidence Policy

## Approved source classes

1. Official SpaceX channels/pages.
2. Trusted agencies/sources:
   - FAA (launch advisory/licensing context)
   - FCC (communications filings)
   - Cameron County / local closure notices
   - Maritime/airspace notices where publicly available
   - NASASpaceflight (trusted reporting)

## Confidence levels

- `confirmed`: official SpaceX source.
- `high`: trusted primary source.
- `medium`: trusted secondary source corroborated.
- `low`: single unconfirmed trusted report.

## Launch countdown rule

Countdown is shown only when an official launch time exists in `launch.official_time_utc`.

## Timezone rule

Display and scheduling semantics target `America/Los_Angeles`.
